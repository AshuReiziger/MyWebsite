# Reiziger Ashu — Personal Website

Personal/brand website for Reiziger Ashu (designer, strategist, educator,
creative leader). The full content strategy, positioning, and page-by-page
copy spec live in `docs/WEBSITE-STRATEGY.md` — read that before writing any
new copy or adding a section, so new content matches the established voice
and narrative arc rather than reading as generic portfolio filler.

## Stack

- Next.js 16 (App Router), TypeScript, Tailwind CSS v4 (CSS-first config —
  there is no `tailwind.config.*`; theme tokens live in `src/app/globals.css`
  under `@theme inline`)
- Content: MDX files in the repo (no headless CMS) via `gray-matter` +
  `next-mdx-remote/rsc`
- `framer-motion` is installed for future motion work (not yet used)
- Deploy target: Vercel

## Commands

- `npm run dev` — dev server
- `npm run build` — production build (also regenerates the typed-route
  globals in `.next/types/routes.d.ts`)
- `npm run lint` — ESLint

## Routing & typed props

Next 16 auto-generates global `PageProps<'/route'>` and
`LayoutProps<'/route'>` types from the filesystem (see
`.next/types/routes.d.ts`, regenerated by `dev`/`build` — never hand-edit
it). Use these instead of hand-writing `params: Promise<{...}>` types:

```tsx
export default async function Page({ params }: PageProps<"/work/[slug]">) {
  const { slug } = await params;
  ...
}
```

`params` and `searchParams` are always `Promise`s in this version — always
`await` them.

## Content model

- `src/content/work/*.mdx` — case studies. Frontmatter:
  `title, client, year, category, coverImage, summary, challenge, insight,
  strategy, impact`. The four `challenge/insight/strategy/impact` fields are
  short structured summaries rendered in the fixed grid by
  `CaseStudyLayout`; the MDX body below is for extended narrative/images.
- `src/content/think/*.mdx` — articles. Frontmatter:
  `title, date, category, excerpt, coverImage`.
- Loaded via `src/lib/content.ts` (`getAllWork`, `getWorkBySlug`,
  `getAllThink`, `getThinkBySlug`). Adding a new `.mdx` file to either
  directory is enough to publish — no code changes needed.
- `[slug]` routes use `generateStaticParams` to prerender every entry at
  build time.

## Design tokens

Defined in `src/app/globals.css` under `@theme inline`, generating standard
Tailwind utilities directly (`bg-ink`, `text-muted`, `border-line`,
`bg-accent`, `font-display`, `font-body`, etc. — no arbitrary-value syntax
needed):

- `ink` / `paper` — primary text / background (inverted in dark mode)
- `muted` — secondary text
- `line` — borders/dividers
- `accent` — CTAs, eyebrows, highlights (bold orange)
- `font-display` (Space Grotesk) for headings, `font-body` (Inter) for body
  text

## Brand voice rules (from `docs/WEBSITE-STRATEGY.md`)

- Never use "Graphic Designer" as a primary title — always "Designer.
  Strategist. Educator. Creative Leader."
- Case studies always follow the 5-part structure: Challenge → Insight →
  Strategy → Design → Impact.
- The site-wide narrative arc is: Who I Am → What I Believe → What I Do →
  What I've Built → What I Think → What I Can Do For You → Let's Build. New
  sections should fit into this arc, not bolt on separately.
