# Reiziger Ashu — Personal Website

Personal website for Reiziger Ashu — designer, strategist, educator, and
creative leader. Built with Next.js (App Router), TypeScript, Tailwind CSS,
and MDX-based content.

See [`docs/WEBSITE-STRATEGY.md`](docs/WEBSITE-STRATEGY.md) for positioning,
content strategy, information architecture, and the technical decision
record. See [`CLAUDE.md`](CLAUDE.md) for project conventions.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

- Case studies live in `src/content/work/*.mdx`
- Articles live in `src/content/think/*.mdx`

Add a new file to either directory (with the required frontmatter fields) to
publish a new entry — no code changes needed.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run lint` — ESLint
